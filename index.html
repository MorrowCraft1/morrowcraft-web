Player Guides & FAQ

Everything you need to know about connecting and playing on MorrowCraft.

Add a new server on Bedrock using server IP play.morrowcraft.net and port 19132 (default Bedrock port). Floodgate handles authentication automatically!
Run /svg or /svg link in game to get your instant login URL for voice.morrowcraft.net. Bedrock users should log into the web client using their dot prefix (e.g. .Username) or set a password with /svg pswd <password>.
Equip a Golden Shovel or run /claim at the corners of your area. You earn claim blocks automatically just by playing on the server!
You can open an appeal ticket directly through our Discord server at discord.morrowcraft.net or click the "Submit Appeal" button below.
